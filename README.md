# 🧠 Trabalhos — Gerenciamento de Banco de Dados (GBD)

Repositório destinado às atividades e projetos desenvolvidos na disciplina **Gerenciamento de Banco de Dados (GBD)**.  
Aqui estão armazenados todos os scripts SQL, documentações e materiais de apoio criados ao longo do curso.

---

## 📚 Sobre a Disciplina

A disciplina **Gerenciamento de Banco de Dados (GBD)** tem como objetivo ensinar os conceitos de:
- Modelagem e normalização de dados  
- Criação e manipulação de bancos de dados relacionais  
- Linguagem SQL (DDL, DML, DCL)  
- Relacionamentos 1:N e N:N  
- Integridade referencial e chaves  
- Operações CRUD (Create, Read, Update, Delete)

---

## 💾 Ferramentas Utilizadas

- **SGBD:** MySQL / MariaDB  
- **Editor:** MySQL Workbench, phpMyAdmin ou DBeaver  
- **Linguagem:** SQL  
- **Ambiente de execução:** Localhost (XAMPP ou similar)

## 🚀 Como Executar os Scripts

1. Abra o **MySQL Workbench** ou **phpMyAdmin**  
2. Copie o conteúdo do arquivo `.sql` correspondente à atividade  
3. Execute o script — ele criará o banco, tabelas e registros automaticamente  
4. Teste as consultas CRUD diretamente no console SQL
